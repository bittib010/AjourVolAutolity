# Security posture
Settings attackers change before credential theft, lateral movement or ransomware: WDigest, LSA protection, Credential Guard, the vulnerable-driver blocklist, Defender (switches, exclusions, tamper protection, services), event logging and ETW, UAC, RDP, the firewall, PowerShell logging and AMSI.
A value set on every host in the fleet is usually Group Policy; a single outlier, or several changes with close *LastWriteTime*, is the signal.
